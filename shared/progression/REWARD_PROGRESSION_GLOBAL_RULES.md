# AFTER SIGNAL 저장·전투 보상 전역 규칙 V1.3

## 새 작전의 명확한 경계

- 타이틀의 `새 작전 시작`은 현재 진행 프로필·미정산 보상·사령관 이름을 지운 뒤 레벨 1, 경험치 0, 재화 0, 이름 미입력 프로필을 새로 만든다.
- 새 빌드의 저장 키 변경만으로 초기화를 대신하지 않는다. 같은 HTML을 다시 실행한 뒤 `새 작전 시작`을 눌러도 반드시 초기화되어야 한다.
- 이름은 시나리오의 이름 확인 장면에서 확정한 뒤 현재 작전 동안 계속 유지한다. 이름 확인 전에는 `사령관` 호칭만 표시한다.
- 설정값(BGM, 효과음, 자동 전투, 컷신 사용 여부)은 새 작전 초기화 대상이 아니다.

## 경험치와 보상

- P-01부터 모든 전투 보상은 승리 후 자동 수령하며 현재 작전 프로필에 누적한다.
- 단일 진행 기준 기대 레벨은 P-01 종료 시 레벨 1/EXP 90, P-02 종료 시 레벨 2/EXP 90, P-04 종료 시 레벨 3/EXP 87이다.
- 보상 화면 새로고침은 같은 토큰으로 중복 지급하지 않는다. 실제 재전투 클리어만 새 토큰을 발급한다.

## 필수 회귀 검사

- 임의로 레벨 7·재화 61,600·이름이 저장된 상태에서 타이틀의 새 작전 시작 동작을 실행한 뒤 레벨 1·재화 0·빈 이름인지 검사한다.
- P-01→P-02→P-04를 한 번씩 정산했을 때 레벨 3/EXP 87과 골드 10,000인지 검사한다.
- 이름 입력 전 빈 이름, 입력 후 재로드 시 동일 이름 유지 여부를 각각 검사한다.
