# AFTER SIGNAL 시나리오 조작 UI 전역 규칙 V1.1

## 고정 규격

- 모든 시나리오 화면 우측 상단 조작은 `HIDE [H]  AUTO [A]  LOG [L]  SKIP [S]` 순서의 한 줄 UI를 사용한다.
- 기호 아이콘, 불투명 버튼 박스, 개별 대형 테두리를 사용하지 않는다. 글자와 작은 라운드 키캡만 표시한다.
- 배경은 투명하며 스토리 배경·인물·대사를 불필요하게 가리지 않는다.
- 데스크톱과 모바일 모두 같은 순서와 기능을 유지하고, 모바일에서는 간격과 글자만 축소한다.

## 입력 계약

- 클릭·터치와 `H`, `A`, `L`, `S` 키는 각각 동일한 동작을 호출한다.
- P-00 최초 진입 화면부터 클릭·터치와 `H/A/L/S` 단축키가 동작해야 한다. P-01 이후에만 활성화되는 구현은 금지한다.
- `#log`가 기록 패널이고 `#logButton`이 버튼인 화면에서는 반드시 실제 `BUTTON`을 선택한다. 패널을 상단 조작부로 이동하거나 버튼처럼 다시 그리지 않는다.
- 화면 자체 단축키와 전역 단축키가 공존해도 한 입력은 한 번만 처리한다. 전역 처리 후 이벤트 전파를 중단한다.
- 텍스트 입력 중에는 단축키를 가로채지 않는다.
- BGM 조작은 이 네 버튼 묶음에 넣지 않고 통합 플레이어의 별도 오디오 제어를 사용한다.

## 제작·회귀 조건

- 이후 추가되는 모든 시나리오는 공통 CSS·런타임을 그대로 사용한다.
- 빌드는 모든 시나리오에 네 버튼, 네 키캡, `aria-keyshortcuts`가 있는지 검사한다.
- 순서·문구·키가 다르거나 구형 기호형 UI가 남아 있으면 배포를 실패 처리한다.
